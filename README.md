# warrant-data

權證篩選網每天盤後自動存下來的「投資人買賣超權證標的」資料（上市＋上櫃、認購＋認售），之後可拿來回測。

- `data/latest.json`：最新一個交易日，網站首頁直接讀這個。
- `data/flow/YYYY-MM-DD.json`、`.csv`：每天一份，CSV 可用 Excel 或 Google 試算表打開。
- `data/index.json`：已存的日期清單（新到舊）。

欄位：代號、名稱、投資人買賣超（萬元）、收盤價、1 日漲幅%、5 日漲幅%。
投資人買賣超 = 發行券商（自營商）買賣超的相反數 × 權證當日成交均價，依標的加總。
資料來源：證交所、櫃買中心公開的盤後資料。

排程：台灣時間週一到週五 17:30（19:30 補跑一次）。要補抓舊日期：Actions → 每日權證籌碼存檔 → Run workflow，填日期。
